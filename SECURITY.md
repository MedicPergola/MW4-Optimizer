# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.0.x   | ✅ Yes             |
| < 1.0   | ❌ No              |

## Reporting a Vulnerability

If you discover a security issue, **do not open a public issue**.  
Please email **medicpergola@proton.me** with:

- A description of the vulnerability  
- Steps to reproduce  
- Affected version(s)

You will receive a response within 48 hours. If the issue is confirmed, a patch will be released as soon as possible.

## Scope

This policy applies to the `MW4_Optimizer.exe` binary and the source code in this repository.  
The tool **does not** interact with game servers, anti‑cheat systems, or online services, so vulnerabilities related to those components are out of scope.
